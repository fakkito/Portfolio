Project Overview

Designed and developed a modern, responsive portfolio website to showcase my projects and skills. Built with clean HTML, CSS, and JavaScript with a focus on user experience and performance.

Features & Implementation

  • Responsive design that adapts seamlessly to all screen sizes.
  • Interactive project carousel with search and filter functionality.
  • Dark/Light theme toggle with localStorage persistence.
  • Multi-language support (French/English) with dynamic content switching.
  • Smooth animations and modern CSS Grid/Flexbox layouts.
  • Contact form integration with Formspree for direct messaging.
