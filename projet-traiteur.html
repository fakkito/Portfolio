Delicatessen Order Management

May - June 2025

Project Overview

Designed and developed a desktop application interface for a delicatessen. The main goal was to streamline order processing and stock management for the business owner.

Key Features

  • Real-time order tracking (ongoing, completed).
  • Advanced weight management for products sold by weight.
  • Intuitive WPF/XAML interface for touch screens.
  • Stock management system with alerts.

Technologies

C# WPF / XAML .NET SQL
